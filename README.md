# Battleship Game in Ruby

This is a simple implementation of the classic game "Battleship", written by me in December 2023, while learning the Ruby language.
The game allows you to play on a customizable grid where you can choose the size of the board and attempt to sink all the ships by guessing their positions.

## Features

- **Customizable Board Size**: You can choose the size of the game board (from 5x5 to 15x15).
- **Random Ship Placement**: Ships are randomly placed on the board, ensuring a unique experience every time.
- **Multi-language Support**: The game supports both English and Japanese languages, allowing you to choose your preferred language at the start.
- **Turn-based Gameplay**: The game tracks your turns and score, providing feedback on whether you hit or missed a ship.
- **Winning Condition**: The game ends when all ships are sunk, and your final score is displayed.

## How to Play

1. Run the program in a Ruby environment.
2. Choose your preferred language (English or Japanese) at the start.
3. Enter the desired size of the game board (between 5 and 15).
4. Input the row and column indices to guess the location of a ship.
5. The game will inform you whether you hit or missed a ship.
6. Continue playing until all ships are sunk.
